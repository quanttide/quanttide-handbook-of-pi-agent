# memory-pin 文案规范

`/memory-pin` 把跨仓库授权写进 `STANDING.md`：该区块每轮注入且 agent 不可写，是唯一能承载授权的地方。本页只管 pin 的文案与预算，分层去处见[pi-hermes-memory 使用规范](./index.md)。

## 文案三条纪律

1. 带边界：用适用范围限定规则（「提交所有更新 = 逐层到底」），删掉边界 agent 遇到新场景只能过度套用或反问；
2. 无论证：不写「因为……所以……」，理由占字符且给重新讨论留抓手；
3. 绝对措辞：用「不得」「不再询问」，不给解释空间。
