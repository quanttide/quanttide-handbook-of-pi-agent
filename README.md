# quanttide-handbook-of-pi-agent

量潮 Pi 智能体手册 — Pi 智能体操作规范与做法。

## 定位

手册收规范：回答「具体怎样做」。与同域（`adapters/quanttide-pi`）资产的分工：

| 资产 | 承担 | 问题 |
|---|---|---|
| `data/context` | 驱动 | 现在带着什么上下文干活？ |
| **handbook（本仓库）** | 规范 | 具体怎样做？ |
| `docs/gallery` | 展示 | 做过哪类事、教训是什么？ |

## 概述

本仓库用于维护量潮 Pi 智能体的操作规范，包括：

- [pi-hermes-memory 使用规范](./pi-hermes-memory/index.md)：记忆四层存放、pin 文案纪律、机制边界、生命周期与验收。
